# Nexus Auth UI

A modern, responsive authentication interface built with HTML5, CSS3, and Bootstrap 5.

## Preview

Nexus Auth is designed as a modern SaaS-style authentication experience with a dark interface, cyan/blue accents, responsive layouts, subtle gradients, and clean typography.

## Features

- Modern Login page
- Modern Sign Up page
- Responsive desktop layout
- Responsive mobile layout
- Split-screen authentication design
- Dark SaaS-style UI
- CSS grid background
- Ambient glow effects
- Custom form controls
- Input focus states
- Button hover animations
- Social login UI
- Login ↔ Sign Up navigation
- Accessible form labels
- Reduced-motion support
- No JavaScript required

## Technologies

- HTML5
- CSS3
- Bootstrap 5
- Google Fonts
