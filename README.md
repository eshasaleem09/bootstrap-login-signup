# Nexus Technologies — Multi-Page Company Website

A responsive multi-page technology company website developed as part of the U DEVS Web Development Internship Program using HTML, CSS, and Bootstrap 5.

## 🌐 Pages

* **Home** — Company introduction, services, statistics, and call-to-action
* **Sign Up** — Responsive registration form with Bootstrap validation
* **Login** — Responsive login interface with password visibility toggle
* **Dashboard** — Employee overview with summary cards and employee table

## ✨ Features

* Responsive Bootstrap 5 navbar
* Mobile-friendly hamburger navigation
* Consistent design across all pages
* Bootstrap grid and responsive utilities
* Service cards and statistics section
* Signup form validation
* Login form validation
* Password show/hide functionality
* Employee dashboard
* Employee status badges
* Responsive employee table
* Shared footer with company and contact information
* Page-to-page navigation

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* Bootstrap Icons
* JavaScript

## 📊 Dashboard Data

The dashboard contains static employee information including:

* Employee name
* Job role
* Department
* Email
* Joining date
* Employment status

No backend or database is used in this project. Employee information is static as required for the internship task.

## 📱 Responsive Design

The website is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile devices

The employee table uses responsive Bootstrap behavior so it can be horizontally scrolled on smaller screens.

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Use the navigation bar to explore the different pages.
